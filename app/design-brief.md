# The Owners Council: design brief

- **Design read:** Business owners ($1M to $25M) and the CPAs, attorneys, bankers and advisors who serve them. Register: calm, private, credible. A room you are invited into.
- **Concept spine:** "The council table." The page walks the visitor down one long table, from the empty dark seat to a lit room overlooking a New England harbor.
- **Delivery tier:** cinema.
- **Locked palette (user brand, overrides banned-family rule):** ink #111111, tints #161616 / #1D1D1D, line #2E2E2E, white #FFFFFF, soft #D6D6D6, muted #A6A6A6, accent #E9702D (41 Legacy orange), accent-deep #C45A1F. Defense: the exact 41 Legacy kit, so the council reads as a 41 Legacy concept.
- **Locked type:** Montserrat 600/700/800 headings, Lato body (41 Legacy brand fonts).
- **Animation mode: animated-website**
- **Journey shape:** single-shot. One 15s continuous dolly push along the council table, split into four contiguous segments so each chapter owns a slice.
- **Journey:** 1 The seat (dark table edge, "Owners decide alone"), 2 The room (lamps, twelve empty chairs, "A room built for owners"), 3 The clarity (bound report with orange tab, "Clarity before change"), 4 The chapters (windows over the harbor, "One standard. Local chapters.").
- **World grammar:** photoreal 35mm anamorphic, walnut table, brass lamps, brick, blue-hour harbor, lamps camera-left, deep blacks, warm tungsten, burnt-orange accents, no people, no text.
- **Mobile framing:** subject center-safe; 720p mobile encodes.
- **Delivery budget:** desktop clips <= 32 MiB total, mobile <= 16 MiB total.
- **Section plan:** journey (4 chapters) / thesis (split text + image, border-top list) / members (bento) / ground rule (full-width quote) / chapters (sticky head + divided list) / advisors (two-column lists, numbered steps, tools, image + form) / invitation (split copy + form) / footer.
- **Asset plan:** storyboard, film, six editorial photoreal plates (council, report, workshop, speaker, advisors, harbor), favicon set, OG card.
- **CTA inventory:** Request an invitation (solid orange, arrow slide), Start a chapter (ghost outline to orange), nav invite (underline text), Start a chapter inline (underline grow), Send my request (solid white to orange), Send chapter inquiry (orange outline fill), Copy the intro (uppercase text button).
- **Firewall:** no internal method names (no assessment product names, no framework names) on the page. Value is described by what members receive.
